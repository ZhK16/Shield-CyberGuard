# BCC Hackathon: два интерактивных прототипа

Одностраничные приложения без бэкенда и сборки. Откройте `index.html` нужной папки в браузере.

| Проект | Что показывает |
|---|---|
| `bcc-shield-ai/` | Поведенческий антифрод и защита от социальной инженерии: Risk Score, AI Explainability, статистика клиента за 12 месяцев, распознавание сценария атаки, «Тихий щит» с ловушкой для мошенника |
| `bcc-cyberguard/` | Обнаружение дроп-сетей, подмены реквизитов (QR/IBAN) и аномалий API-сессий: Threat Score, четыре модуля проверки, журнал инцидентов |

## Запуск
Достаточно открыть файл в браузере. Нужен интернет для CDN (Chart.js, Tailwind, Lucide) и шрифтов.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root. Сайты будут доступны по адресам `/bcc-shield-ai/` и `/bcc-cyberguard/`.

## Важно
Все данные демонстрационные и условные: имена, счета, ID сеансов, отчёты в правоохранительные органы (отправка имитируется). Модели скоринга прозрачны и взвешены вручную, это прототип, а не промышленная система.
